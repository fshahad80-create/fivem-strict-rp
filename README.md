# fivem-strict-rp

سيرفر FiveM للحياة الواقعية المشددة — مبني على **QBCore**.

## الأنظمة

| النظام | الحالة |
|---|---|
| العقوبات التلقائية (سجن/غرامات/حظر) | جاهز |
| الاقتصاد الواقعي (رواتب/ضرائب/تضخم/فواتير/تأمين) | جاهز |
| الاحتياجات/الصحة/الطقس | قادم |
| قوانين RP + الإشراف | قادم |

## النظام 1: العقوبات

- نقاط تصاعدية: تحذير 10 -> غرامة 25 -> سجن 45 -> مشدد 70 -> مراجعة حظر 100.
- تصعيد تكرار (1.0x إلى 2.0x) + حكم آلي عند القبض.
- نظام مطلوبين (Wanted) + سحب رخص + حظر تلقائي + سجن فعلي مع عدّاد.

## النظام 2: الاقتصاد

- **رواتب**: 8 وظائف، base + مضاعف الرتبة، تُصرف كل 30 دقيقة (on-duty فقط)، مع بونص إنجاز.
- **ضرائب دخل شرائحية**: 8% -> 25% حسب الدخل.
- **ضرائب ممتلكات**: يومية لكل عقار/مركبة.
- **تضخم آلي**: +0.2% بالساعة، سقف 160%، يرفع أسعار المتاجر والفواتير.
- **فواتير دورية**: كهرباء/ماء/هاتف/إيجار كل 4 ساعات، والتأخر => غرامة + نقاط عقوبات.
- **تأمين مركبات**: قسط دوري، تغطية 80% من الإصلاح.

> الروابط بين النظامين: التأخر في السداد أو عدم دفع التأمين يُغذّي نظام العقوبات تلقائياً.

## التركيب

1. ضع المجلد في `resources/`.
2. تأكد من تثبيت `oxmysql` و `qb-core`.
3. نفّذ `database.sql` (أو اتركه — يُنشأ تلقائياً).
4. أضف `ensure fivem-strict-rp` في `server.cfg`.

## الأوامر

| الأمر | الصلاحية | الوظيفة |
|---|---|---|
| `/points [id]` | admin | عرض نقاط العقوبات |
| `/clearpoints [citizenid]` | admin | تصفير النقاط |
| `/record [id]` | admin | عرض السجل الجنائي |
| `/inflation` | user | عرض مؤشر التضخم |
| `/setinflation [v]` | admin | ضبط التضخم يدوياً |
| `/bills` | user | عرض فواتيرك |

## التعديل

كل الإعدادات في `config/` — لا تعدّل ملفات السيرفر.
