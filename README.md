# fivem-strict-rp

سيرفر FiveM للحياة الواقعية المشددة — مبني على **QBCore**.

## الأنظمة

| النظام | الحالة |
|---|---|
| العقوبات التلقائية (سجن/غرامات/حظر) | جاهز |
| الاقتصاد الواقعي (رواتب/ضرائب/تضخم) | قادم |
| الاحتياجات/الصحة/الطقس | قادم |
| قوانين RP + الإشراف | قادم |

## نظام العقوبات

- **نقاط تصاعدية**: كل مخالفة تضيف نقاطاً؛ العتبات: تحذير 10 -> غرامة 25 -> سجن 45 -> مشدد 70 -> مراجعة حظر 100.
- **تصعيد**: المخالفة المتكررة ترتفع عقوبتها (1.0x إلى 2.0x).
- **حكم آلي عند القبض**: تُجمع كل الجرائم المسجلة على اللاعب وتُحسب عقوبة واحدة.
- **نظام مطلوبين (Wanted)**: بث الموقع للشرطة، مع عدّاد.
- **سحب رخص** + **حظر تلقائي** + توثيق Discord اختياري.
- **سجن فعلي** مع واجهة عدّاد ومنع الهروب (تمديد العقوبة عند المحاولة).

## التركيب

1. ضع المجلد في `resources/`.
2. تأكد من تثبيت `oxmysql` و `qb-core`.
3. نفّذ `database.sql` (أو اتركه — يُنشأ تلقائياً).
4. أضف `ensure fivem-strict-rp` في `server.cfg`.

## الأوامر

| الأمر | الصلاحية | الوظيفة |
|---|---|---|
| `/points [id]` | admin | عرض نقاط العقوبات |
| `/clearpoints [citizenid]` | admin | تصفير النقاط |
| `/record [id]` | admin | عرض السجل الجنائي |

## التعديل

كل الإعدادات في `config/penalties.lua` — لا تعدّل ملفات السيرفر.
