# fivem-strict-rp

سيرفر FiveM للحياة الواقعية المشددة — مبني على **QBCore**.

## الأنظمة الأربعة

| النظام | الحالة |
|---|---|
| 1. العقوبات التلقائية (سجن/غرامات/حظر) | جاهز |
| 2. الاقتصاد الواقعي (رواتب/ضرائب/تضخم/فواتير/تأمين) | جاهز |
| 3. الاحتياجات/الصحة/الطقس | جاهز |
| 4. قوانين RP + الإشراف | جاهز |

## النظام 1: العقوبات

- نقاط تصاعدية: تحذير 10 -> غرامة 25 -> سجن 45 -> مشدد 70 -> مراجعة حظر 100.
- تصعيد تكرار (1.0x إلى 2.0x) + حكم آلي عند القبض.
- نظام مطلوبين (Wanted) + سحب رخص + حظر تلقائي + سجن فعلي مع عدّاد.

## النظام 2: الاقتصاد

- **رواتب**: 8 وظائف، base + مضاعف الرتبة، كل 30 دقيقة (on-duty فقط)، مع بونص إنجاز.
- **ضرائب دخل شرائحية**: 8% -> 25% حسب الدخل.
- **تضخم آلي**: +0.2%/ساعة، سقف 160%.
- **فواتير دورية**: كهرباء/ماء/هاتف/إيجار كل 4 ساعات، والتأخر => غرامة + نقاط عقوبات.
- **تأمين مركبات**: قسط دوري، تغطية 80% من الإصلاح.

## النظام 3: الاحتياجات والطقس

- **جوع/عطش/طاقة/نظافة**: تنقص مع الوقت بمعدلات قابلة للضبط.
- **تأثيرات فعلية**: تباطؤ الجري، ضرر عند النفاد، فقدان وعي عند الإنهاك.
- **طقس حي**: يتبدل كل 20 دقيقة، ويؤثر على المعدلات.
- **مزامنة**: كل اللاعبين على نفس الطقس والوقت.

## النظام 4: القوانين والإشراف

- **17 قاعدة RP مصنّفة**، لكل قاعدة وزن نقاط.
- **نظام تقارير**: رفع تقرير ضد لاعب + قائمة معلقة للستاف.
- **أدوات ستاف**: /warn /kick /sjaill /ban /note /reports /handlereport.
- **نقاط إشراف متراكمة** تتصاعد آلياً: إنذار -> إنذار مشدد -> سجن إداري -> حظر -> حظر دائم.
- **سجل دائم** لكل إجراء + توثيق Discord اختياري.

## التركيب

1. ضع المجلد في `resources/`.
2. تأكد من تثبيت `oxmysql` و `qb-core`.
3. نفّذ `database.sql` (أو اتركه — يُنشأ تلقائياً).
4. أضف `ensure fivem-strict-rp` في `server.cfg`.

## الأوامر

| الأمر | الصلاحية | الوظيفة |
|---|---|---|
| `/points` `/record` | admin | نقاط العقوبات / السجل الجنائي |
| `/inflation` `/setinflation` | user/admin | التضخم |
| `/bills` | user | فواتيرك |
| `/needs` `/setweather` `/feed` | user/admin | الاحتياجات / الطقس |
| `/report` `/reports` `/handlereport` | user/admin | التقارير |
| `/warn` `/kick` `/sjaill` `/ban` `/note` | admin | إجراءات الستاف |
| `/staffpoints` `/stafflog` | admin | نقاط وسجل الإشراف |

## التعديل

كل الإعدادات في `config/` — لا تعدّل ملفات السيرفر.
