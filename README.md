## 🔧 التركيب

1. ضع `fivem-strict-rp/` و `loading/` في `resources/`.
2. ثبّت `oxmysql` و `qb-core`.
3. نفّذ `database.sql` (أو اتركه — ينشأ تلقائياً).
4. أضف في `server.cfg`:
   ```
   ensure oxmysql
   ensure qb-core
   ensure fivem-strict-rp
   ensure AL-FORSAN-RP-Loading
   ```
